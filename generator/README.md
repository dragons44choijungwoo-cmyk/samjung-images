# 삼정 카페 글 만들기

"○개 만들어줘"라고 하면 이 폴더로 글을 ○개 만들어 미리보기 페이지에 올립니다.
미리보기 페이지: https://claude.ai/artifact/46huJGvcRdpdRqk3a2hCQG (글 선택 목록에서 글을 고르고 "본문 전체 복사")

## 글 규칙 (build.py가 확인)

- 본문 1900~2000자, 공백 제외로 셉니다 (이모지는 1자). 마지막 카톡/전화/링크 줄은 포함, 제목·해시태그·사진(사진 속 글자)은 제외. 공백 포함으로는 대략 2,400~2,550자입니다
- 인용구 7개 이상, 빨간색 `<r>..</r>`과 남색 `<n>..</n>` 포인트
- 제목에 키워드와 부산 구/동 이름
- 삼정 영업 내용: 블로그 글 한 건 5만 원, 최적 블로그로 70% 이상 상위노출.
  홈페이지 관련 글이면 AI 제작, AI를 원하지 않는 대표님께는 전문 디자이너의 커스텀 디자인, 예약·회원·결제 같은 플랫폼 기능 개발도 가능하다고 안내
- 사진 5장: 대표 이미지(로고+모델), 본문 그림 3장, 마지막 "카카오톡으로 무료 상담받기" 이미지.
  모든 사진에 카톡 링크가 찍혀 있고, 누르면 카톡 상담으로 연결
- 끝부분: 문의 이미지, 카톡 링크(https://open.kakao.com/o/sWb5ALAi), 전화(010-8076-5711), `https://samjung.ai.kr/?ref=<키워드>`

## ○개 만드는 순서

1. 키워드 고르기: 구글 시트 "🔺삼정 블로그"의 **"혜민 삼정"** 탭(13행부터: C 키워드, D 검색량, E 작성자)에서, 아직 작성자가 없고 `posts/`에도 없는 키워드를 검색량이 높은 순으로 후보로 뽑습니다.
   ("삼정 키워드" 탭은 쓰지 않습니다.)
   글마다 시트 1~9행의 부산 구/동 중 하나를 골라 제목에 넣고, 글끼리 지역이 겹치지 않게 합니다.
2. 준최 확인: 후보마다 블로그 연구소(https://lablog.co.kr)에서 준최 키워드인지 확인하고, 준최인 키워드만 ○개 씁니다.
   블로그 연구소에 접속할 수 없으면 후보 목록을 choi에게 보여 주고 확인을 받은 뒤 씁니다.
3. 글 쓰기: 글 하나당 `posts/<날짜>-<영문-슬러그>.json` 파일 하나. 기존 파일을 본보기로 씁니다.
   - `blocks`: `p`, `quote`, `h2`, `ul`, `img`, `kakao`, `phone`, `link`
   - `images`: 사진 설정. `cover`(대표), `rows`(표), `steps`(단계), `check`(체크리스트), `cta`(문의).
     모델 사진은 `front`, `thinking`, `pointing` 중에서 고릅니다. 파일 이름은 `-v1.png`로 끝납니다.
4. 사진 그리기: `NODE_PATH=$(npm root -g) node render.js` (없는 사진만 그려서 저장소의 `posts/` 아래에 저장)
5. 확인과 페이지 만들기: `python3 build.py`가 규칙을 확인하고 `out/samjung-cafe-post.html`을 만듭니다. 이어서 `NODE_PATH=$(npm root -g) node verify.js`
6. 올리기: 새 사진과 글 파일을 커밋해서 `main`에 푸시합니다 (네이버가 사진을 이 공개 주소에서 가져감).
   그다음 `out/samjung-cafe-post.html`을 위 미리보기 페이지 주소로 다시 게시하고, 새 사진도 같은 경로(`posts/...`)의 파일로 함께 올립니다.

사진을 고칠 때는 파일 이름의 버전(`-v1` → `-v2`)을 올립니다. GitHub 공개 주소는 몇 분 동안 예전 사진을 보여 주기 때문입니다.
로고와 모델 사진 원본은 이 공개 저장소가 아니라 프로젝트 파일 `/mnt/project-files/blog/assets`에 있습니다.
